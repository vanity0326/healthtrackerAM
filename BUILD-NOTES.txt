Daily Tracker - Version 2.2.0 build notes

Static app assets: public/
Netlify Functions: netlify/functions/
Shared tracker data: Netlify Blobs store daily-health-tracker / shared-state
Workbook history source: history-import.json (project root)
Workbook history seed for automatic local and first-deploy display: public/seed-history.js
Local cache: browser localStorage; JSON backup available in More.
Cross-device data endpoint: /api/data (no sign-in, per user preference).
Device reminder endpoint: /api/reminders (separate authenticated setup key).

Version 2.2.0 adds five read-only measurement cards backed by the Weight tab's existing weekly weigh-ins, plus predefined monthly cards for neck, shoulders, chest, band (chest), bicep, waist, hips, thigh, and calf. Custom monthly measurement types remain available. Daily Log and history import, targets, reminders, and Netlify Blobs synchronization are retained from Version 2.1.0.
