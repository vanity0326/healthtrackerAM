Version 6.0.1 — consolidated release

- Implemented working Add amount, Add bottle, and Clear total actions for fluid tracking.
- Added beverage categories and stacked flask visualization: water (blue), diet soda (dark brown), tea (light brown), juice (orange), and other beverages (light purple).
- Fluid amount and bottle size are recorded in ounces; bottle size and daily reference amount are configurable in More > Water settings.
- Legacy V5 waterOz entries are preserved and carried forward as water when a new beverage is added.
- Added daily notes save handling and Notes History to Progress Review.
- Moved the consistency calendar to the first metric/card on Progress Review; dates can be opened for editing.
- Clear total confirms before removing the selected date's beverage entries. Other daily records remain intact.
- Live Netlify deployment is not modified by this source package.

Validation: JavaScript syntax check and ZIP integrity check performed. Browser end-to-end interaction testing was not available in this environment; test with a copy of your existing data before deployment.

Release identity: package version 6.0.1; visible app version 6.0; service-worker cache daily-tracker-shell-v6-0-0.


Version 6.0.1 update: Fluid tracking has its own date selector, defaulting to the current local date, independent of the daily log date (which defaults to yesterday). Existing entries are not moved.
